# Exp:7 - Expectation–Maximization for the Two-Coin Flipping Experiment

This project implements the coin-flipping **Expectation–Maximization (EM)** example demonstrated in the supplied video. It estimates the probability of heads for two coins when the identity of the coin used in each experiment is unknown.

The implementation is intentionally a **mixture-of-coins model**, not a Hidden Markov Model (HMM). One hidden coin generates an entire experiment of ten tosses; the coin does not switch within that experiment.

## Experiment setup

There are two coins:

- **Coin A** with unknown head probability `theta_A`
- **Coin B** with unknown head probability `theta_B`

Five independent experiments are observed. Every experiment contains ten tosses, but the coin selected for that experiment is hidden.

| Experiment | Tosses | Heads | Tails |
| --- | --- | ---: | ---: |
| E1 | `H T T T H H T H T H` | 5 | 5 |
| E2 | `H H H H H T H H H H` | 9 | 1 |
| E3 | `H T H H H H H T H H` | 8 | 2 |
| E4 | `H T H T T T H H T T` | 4 | 6 |
| E5 | `T H H H T H H H T H` | 7 | 3 |

The initial estimates used in the video and in this program are:

```text
theta_A = 0.60
theta_B = 0.50
P(Coin A selected) = 0.50
P(Coin B selected) = 0.50
```

`theta_A` and `theta_B` are the values to be learned. For example, `theta_A = 0.60` means Coin A is currently estimated to produce heads 60% of the time.

## Why EM is needed

If we knew which coin created every experiment, estimating each coin would be simple: count its heads and divide by its total tosses.

However, the coin identity is hidden. EM solves this missing-information problem by alternating between:

1. **E-step:** estimate how likely each experiment came from Coin A or Coin B.
2. **M-step:** use those probabilities as fractional counts to update each coin’s probability of heads.

This repeats until the parameter estimates stop changing appreciably.

## How the code matches the video

### E-step: probability that a coin generated an experiment

For an experiment containing `h` heads and `t` tails, and a coin with head probability `theta`, the probability of those counts is:

```text
P(E | coin) = C(h + t, h) * theta^h * (1 - theta)^t
```

The program then uses Bayes’ rule to calculate the responsibility of Coin A:

```text
P(A | E) = P(A) * P(E | A) /
           [P(A) * P(E | A) + P(B) * P(E | B)]
```

Because both coins begin with equal selection probability (`0.5`), the formula reduces to the likelihood comparison shown in the video.

In the first iteration, the code produces these approximate E-step responsibilities:

| Experiment | P(Coin A given experiment) | P(Coin B given experiment) |
| --- | ---: | ---: |
| E1: 5 H, 5 T | 0.4491 | 0.5509 |
| E2: 9 H, 1 T | 0.8050 | 0.1950 |
| E3: 8 H, 2 T | 0.7335 | 0.2665 |
| E4: 4 H, 6 T | 0.3522 | 0.6478 |
| E5: 7 H, 3 T | 0.6472 | 0.3528 |

For example, E2 has nine heads and one tail, so it is much more likely to have been generated by Coin A when `theta_A = 0.60` and `theta_B = 0.50`.

### M-step: update the coin biases

The responsibility values are used as fractional assignments. For E2, for example, approximately 80.5% of its nine heads and one tail are credited to Coin A; the remaining 19.5% are credited to Coin B.

After summing all fractional counts in iteration 1, the program obtains approximately:

```text
Coin A: 21.2975 expected heads, 8.5722 expected tails
Coin B: 11.7025 expected heads, 8.4278 expected tails
```

The M-step updates each bias by dividing expected heads by expected total tosses:

```text
theta_A = expected_heads_A / (expected_heads_A + expected_tails_A)
theta_B = expected_heads_B / (expected_heads_B + expected_tails_B)
```

After the first M-step:

```text
theta_A = 0.7130
theta_B = 0.5813
```

These values correspond to the approximately `0.71` and `0.58` updates shown in the video. Repeating E-step and M-step refines the parameters further.

Spaces and lowercase letters are accepted and normalized. Any other character raises a `ValueError`.

The main training function is:

```python

```

| Argument | Meaning |
| --- | --- |
| `experiments` | List of independent `Experiment` objects. One hidden coin creates each complete experiment. |
| `theta_a` | Initial estimate of Coin A’s probability of heads. |
| `theta_b` | Initial estimate of Coin B’s probability of heads. |
| `prior_a` | Prior probability that Coin A was selected for an experiment. `0.50` matches the video; Coin B receives `1 - prior_a`. |
| `max_iter` | Maximum number of EM iterations. |
| `tol` | Convergence threshold for log-likelihood improvement. |

2. The first E-step responsibilities for Coin A and Coin B.
3. The first M-step fractional head/tail counts and updated parameter estimates.

The log-likelihood increases from one EM iteration to the next, which indicates that the model is fitting the observed experiments better.

```
import numpy as np
from scipy.stats import binom

def em_coin_flipping_converge(tolerance=1e-8):
    experiments = [
        (5, 5),
        (9, 1),
        (8, 2),
        (4, 6),
        (7, 3)
    ]

    theta_a = 0.60
    theta_b = 0.50
    prior_a = 0.50
    prior_b = 1 - prior_a

    iteration_count = 0
    first_step = True

    print("--- EXPERIMENT DATA ---")

    for i, (heads, tails) in enumerate(experiments, 1):
        print(f"E{i}: Heads = {heads}, Tails = {tails}")

    while True:
        iteration_count += 1

        expected_heads_a = 0.0
        expected_tails_a = 0.0
        expected_heads_b = 0.0
        expected_tails_b = 0.0

        if first_step:
            print("\n--- FIRST E-STEP ---")

        for i, (heads, tails) in enumerate(experiments, 1):
            n = heads + tails

            likelihood_a = binom.pmf(heads, n, theta_a)
            likelihood_b = binom.pmf(heads, n, theta_b)

            prob_a = (
                prior_a * likelihood_a
                / (prior_a * likelihood_a + prior_b * likelihood_b)
            )

            prob_b = 1 - prob_a

            expected_heads_a += prob_a * heads
            expected_tails_a += prob_a * tails

            expected_heads_b += prob_b * heads
            expected_tails_b += prob_b * tails

            if first_step:
                print(
                    f"E{i}: P(A|E) = {prob_a:.4f}, "
                    f"P(B|E) = {prob_b:.4f}"
                )

        new_theta_a = expected_heads_a / (
            expected_heads_a + expected_tails_a
        )

        new_theta_b = expected_heads_b / (
            expected_heads_b + expected_tails_b
        )

        if first_step:
            print("\n--- FIRST M-STEP ---")
            print(
                f"Coin A: Expected Heads = {expected_heads_a:.4f}, "
                f"Expected Tails = {expected_tails_a:.4f}"
            )
            print(
                f"Coin B: Expected Heads = {expected_heads_b:.4f}, "
                f"Expected Tails = {expected_tails_b:.4f}"
            )
            print(f"New Theta A = {new_theta_a:.4f}")
            print(f"New Theta B = {new_theta_b:.4f}")
            first_step = False

        if (
            abs(new_theta_a - theta_a) < tolerance
            and abs(new_theta_b - theta_b) < tolerance
        ):
            theta_a = new_theta_a
            theta_b = new_theta_b
            break

        theta_a = new_theta_a
        theta_b = new_theta_b

    print("\n--- CONVERGENCE REACHED ---")
    print(f"Algorithm converged after {iteration_count} iterations.")
    print(f"Final Theta A = {theta_a:.4f}")
    print(f"Final Theta B = {theta_b:.4f}")
    print(f"Coin A probability of Heads = {theta_a:.2f}")
    print(f"Coin B probability of Heads = {theta_b:.2f}")


if __name__ == "__main__":
    em_coin_flipping_converge()
```
